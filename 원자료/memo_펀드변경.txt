※ 교육용 가상 자료입니다. 실제 회사 규정·시스템과 무관합니다.

펀드변경 처리할 때 메모 (내가 보려고 적어둔 거)

- 신청 들어오면 먼저 계약 상태부터 봐야 함. 유지 아니면 처리 X (실효, 납입유예 중인 건 반려)
- 변경 종류 2개: 적립금 이전(이미 쌓인 돈 옮기는 거) / 투입비율 변경(앞으로 낼 보험료 비율)
  -> 둘 다 같이 신청하는 경우도 있음. 그럼 건 2개로 나눠서 입력
- 올해 변경 횟수 확인!! 연 12회까지 무료. 13회차부터 건당 2,000원 (적립금에서 차감)
  계산: 수수료 = MAX(0, 올해 변경횟수(이번 건 포함) - 12) x 2,000
- 비율 합계 100% 아니면 화면에서 에러남 (E-102). 10% 단위만 됨 (15% 이런 거 안 됨, E-103)
- 펀드는 최대 5개까지 편입 가능. 6개 이상이면 E-104
- 판매중지 펀드로는 옮길 수 없음 -> 펀드목록 엑셀에서 sale_status 꼭 확인 (작년에 이거 놓쳐서 재처리함ㅠ)
- 기준가는 신청일 +2영업일 기준가로 적용됨. 고객 문의 오면 이거 안내
- 처리 화면: [계약조회] -> [변액] 탭 -> [펀드변경 신청] 버튼 -> 펀드/비율 입력 -> [검증] -> [저장]
  검증 누르기 전에 저장 누르면 안 됨
- 처리 끝나면 체크리스트 엑셀에 결과 기록 + 조회 쿼리로 반영됐는지 다음날 확인
- 고객 위험성향보다 위험등급 높은 펀드(등급 숫자가 작을수록 위험)로 바꾸면 적합성 확인서 받아야 함. 없으면 보완요청
- 콜센터 접수건은 녹취 확인 필요, 창구 접수건은 신청서 원본 확인

헷갈리는 거
- 적립금 이전은 '전액' 아니면 % 단위로만
- 같은 날 두 번 신청하면 마지막 건만 유효 (앞에 건 취소처리)
