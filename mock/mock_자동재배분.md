# 1. 업무개요

변액보험 계약자가 신청하면, 정한 주기마다 펀드 적립금 비율을 최초 설정 비율로 자동 조정하는 업무이다. [메모]

- 주기: 3개월 / 6개월 / 12개월 중 선택 [메모]

# 2. 관련규정

| 항목 | 기준 |
|---|---|
| 재배분 주기 | 3·6·12개월 중 필수 선택 [메모] |
| 기준 비율 | 신청 시점의 투입비율로 자동 설정 [메모] |
| 펀드변경 횟수 | 연간 무료 횟수(12회)에 포함되지 않음 [메모] |
| 판매중지 펀드 | 편입 펀드 중 하나라도 있으면 신청 불가 [메모] |
| 수수료 | [확인 필요] |
| 재배분 기준일 | [확인 필요] |

# 3. 업무흐름도

① 신청 접수 → ② 판매중지 펀드 포함 여부 확인 → ③ 주기 선택·신청 → ④ 주기마다 자동 재배분 → ⑤ 펀드변경 발생 시 자동 해지 안내 [메모]

# 4. 처리절차

3. 편입 펀드 중 판매중지 펀드가 있으면 신청할 수 없다. [메모]
